# SurvForge 模型卡（Model Card）

## 用途
- **任务**：右删失时间-事件数据的风险排序（risk ranking），输出分数越大风险越高。
- **预期场景**：合成基准评测、生存分析方法论教学与对比实验、离线环境下的方法验证。
- **非预期用途**：真实临床/金融决策。合成数据上验证的方法论，迁移到真实数据前必须
  重新校准与验证。

## 数据
- 合成 Weibull DGP（k=1.2, λ=0.05），8 特征（6 项进入风险函数），信息性删失，
  事件率 ~0.55-0.75，n = train 1000 / val 400 / holdout 800，seed 固定可复现。
- 支持外部 CSV（需含 `time`、`event` 列，其余为特征列）。

## 指标（holdout，3 seeds mean±std）
- 主指标：Harrell C-index；次指标：简化 Uno IPCW C-index（KM 删失加权）。
- 旗舰 fusion_hpo：0.7855 ± 0.0086；经典强基线 Cox PH：0.7124 ± 0.0031（Δ=+0.0732 显著）。
- 详细表与 failure cases 见 benchmark.json。

## 局限
1. 合成 DGP 上结论不自动迁移到真实数据（尤其非 PH 效应、时变协变量场景未覆盖）；
2. 旗舰融合 vs 最强单模型（xgb_aft）仅非劣（+0.0004）：融合价值依赖成员误差异构，
   当单一成员近似贝叶斯最优时融合无增益——使用前应先诊断成员强度差；
3. 样条 Cox 在小样本（n≲300）高维基下不稳定，建议 n≥800 或降低 n_knots；
4. 简化 Uno C 未做逐对 G(t_j) 截断，重删失场景请以 scikit-survival 完整实现复核；
5. 纯 CPU 设计，未针对 GPU/分布式扩展。
